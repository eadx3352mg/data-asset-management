# DAMA-DMBOK 数据资产管理体系与解决方案实战

**架构师版｜面向数据架构师、解决方案专家、数据治理工程师及 AI 数据平台建设**

这是一套基于 **DAMA-DMBOK**，结合数据治理、数据平台、数据要素、可信数据空间及 AI 发展进行的系统性知识整理。

内容不以 DAMA 考试和概念解释为目标，而更关注三个问题：**为什么需要、如何建设、如何落地**。希望在 DAMA 十一大知识域的基础上，进一步建立从数据管理体系、工程实践到解决方案设计的完整认知。
